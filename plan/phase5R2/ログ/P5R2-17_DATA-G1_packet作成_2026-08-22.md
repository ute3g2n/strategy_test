## 1. 実施内容

P5R2-16 GREENを入力に、P5R2-CREQ-HD-001／002、P5R2-UNK-HD-004、P5R2-UNK-QG-001／002を追跡し、P5R2-18で実Provider受入を行う場合の対象、期限、保存先、allowlist、Secret、費用、停止、rollback、usable昇格条件を1 packetへ集約した。P5R2-17では外部hostへの接続、login、契約、API call、Data download、Secret読取、費用発生を行っていない。

推奨する最小bounded pilotは、Binance Data Vision public archive、Spot、BTCUSDT／ETHUSDT、source 1m、UTCの2025-02-24以上2025-03-01未満、月次zipとCHECKSUM、最大4 archive objectである。15m／30m／1h／4h／1dはproviderから取得せず、local source 1mから生成する。推奨値は無制限のProvider承認ではなく、P5R2-18の受入Runだけに束縛する。

## 2. 公式一次情報のread-only確認

2026-08-23に次の公開ページを閲覧した。閲覧以外の操作はしていない。

| URL | 確認結果 |
|---|---|
| https://github.com/binance/binance-public-data/blob/master/README.md | 公開Data Collection、daily／monthly archive、Spot kline、interval、download URL、CHECKSUM、archive updateの記載を確認。市場Dataの再配布許諾・料金・今回の完全期間は未確認。 |

公式READMEにあるMIT表記は公開リポジトリのコード説明であり、市場Dataの保持・再配布許諾へ拡張していない。したがって、承認後もraw provider Dataの再配布を禁止し、terms Unknownを残す。

## 3. Packetの主な停止条件

- allowlist外host、REST／WebSocket、redirect、proxy、login、Secret、課金表示を検出したら停止する。
- source 1m以外、Spot以外、承認外symbol／期間、schema／timestamp／UTC／重複／欠損不一致はusableへ昇格しない。
- process-level egress guardとhost-level isolationを別Evidenceにし、host-level未確認をCONFIRMEDと書かない。
- partial download、cancel、restart、promotion途中失敗はstaging隔離またはRECOVERY_REQUIREDとし、current pointerを更新しない。
- DELETE-G1未承認のため、既存Historical Data、Run、CSV、Audit、Evidenceの物理削除・cascadeは行わない。

## 4. Runtime truth

指定Coordinator／Agent rosterの独立dispatchは成立していないため、runtime receiptには`NOT_DISPATCHED`、`independent=false`、`SELF_REVIEW_FALLBACK`を記録する。P17の成果物はrootによるpacket統合と公開一次情報のread-only確認であり、指定Agentが実行済みとは扱わない。A95 runtime agentも未起動であり、対象文書の静的fallback判定を別Evidenceへ記録した。

## 5. 結論

P5R2-17のAcceptanceを満たすpacketを作成した。DATA-G1はpacket作成だけでは承認済みにならない。承認判断後にのみP5R2-18の実Provider受入を開始し、承認されない場合はP5R2-18を停止したままP5R2-19のlocal UI統合へ進む。
