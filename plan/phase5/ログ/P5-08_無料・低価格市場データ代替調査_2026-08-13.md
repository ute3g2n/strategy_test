## 1. 結論

現在のP5要件（MCL/M6A/MZC/MZS/MZW、CME先物、17か月、1分足、D1/H4/H1/M30/M15派生、個別契約、UTC、Calendar/Roll/Quality/Manifest証跡）を、無料で同じ意味のまま満たす候補は確認できなかった。

最も現実的な低価格候補は Sierra Chart Historical Data Service。公式説明ではHistorical daily/intraday、多くの先物のtick履歴、Standard/Advanced packageへの内包、CSV/Text export、UTC exportを確認できる。Base Standardは公式価格ページで26 USD/月と表示される。ただし、5銘柄の実symbol、期間、1分足、Volume、Open Interest、限月、Roll、利用条件は未確認で、採用前の小規模PoCを必須とした。

完全無料の候補（Yahoo/yfinance、Nasdaq Data Link、Stooq、CME公式Settlement）は、主に日足または参照用途であり、1分足から5つの時間足を作る現在P5の代替にはしない。HistData/Dukascopy/TrueFXはFX/CFD、Binance/CoinbaseはCryptoであり、資産種類変更後の別Trackとした。

## 3. 調査対象と判定

| 区分 | 候補 | 判断 |
|---|---|---|
| Exact futures / low cost | Sierra Chart Historical Data Service | 第一候補。PoC必須。 |
| Existing account route | Interactive Brokers TWS API | 既存口座・subscriptionがある場合の条件付き候補。 |
| Free daily research | Yahoo/yfinance | 日足prototype・照合のみ。 |
| Free/paid catalog | Nasdaq Data Link | dataset/CHRISの現行availabilityを要確認。 |
| Free EOD | Stooq | 現行access/terms/symbolがUnknown。 |
| Official daily reference | CME settlements / Volume / Open Interest | 日次照合用。 |
| Free FX intraday | HistData、Dukascopy、TrueFX | FX/CFD proxyでありP5直接代替不可。 |
| Low-cost generic APIs | Alpha Vantage、Twelve Data | CME Micro futuresの直接代替根拠なし。 |
| Free crypto intraday | Binance、Coinbase | CryptoへScope変更する場合のみ。 |
| Platform candidate | NinjaTrader | Free planは確認したが、独立したbulk Data sourceとしての適合は未確認。 |

## 4. 推奨方針

1. CME futuresと1分足を守る場合は、Sierra Chartで5銘柄を検証する。
2. 完全無料を優先する場合は、P5を日足prototypeへ正式に縮小する。
3. 無料intradayを優先する場合は、CryptoまたはFX/CFDを別資産の新しいScopeとして設計する。
4. Provider変更時は、現行P5-DATA-G1を自動流用せず、新しいamendment、DataRequest、Runner、Run ID、Manifest、Human Gateを作る。

## 5. 採用前PoC

1. Sierraのsymbol一覧でMCL/M6A/MZC/MZS/MZW、個別限月、2025-02-24以降のavailable historyを確認する。
2. MCL/M6A、続いて農産物3銘柄を各1営業日だけ1分足でexportする。
3. UTC、OHLCV、Volume、Open Interest、session、expiry、venue、tick、Calendar/DSTを記録する。
4. CME公式SettlementのD1と突合し、CSV/hash/取得条件をEvidenceへ保存する。
5. P5-NORMALIZED-BAR-v1.0.0へ変換し、Raw/Normalized/Quality/Manifest境界を確認する。
6. 1日PoCのCritical/High=0、Unknownの停止条件解消後だけ全期間へ拡張する。
