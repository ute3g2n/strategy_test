## 1. 引渡しの意味

この文書は、P5で確認した市場Dataの設計・品質・追跡情報をP6の計画入力へ渡す一覧である。P5-H2の承認は、残存Unknownを解消済みとする承認ではない。P6は、下記のUnknownと停止条件を入力として扱い、根拠を得るまで外部実行・実運用へ進めない。

## 2. 固定Data contract

| 項目 | P6へ渡す値 | 制約 |
|---|---|---|
| Provider | Binance Data Vision historical公開アーカイブ | 利用・保持・再配布条件はUnknown。根拠取得まで外部実行を再開しない |
| Asset / market | `crypto` / `spot` | Futures、Funding、Liquidation、Optionsは対象外 |
| Symbol | `BTCUSDT`, `ETHUSDT` | 他のsymbolは別Gate。自動追加しない |
| Base data | Spot Kline `1m`月次ZIP、Raw、展開CSV、Normalized | Tick、order book、trade stream、REST API拡張は含めない |
| Timezone | UTC | timestamp unitはEvidenceの検査結果を引き継ぎ、推測しない |
| Calendar | `CRYPTO_24_7_UTC` | DST、CME休場、限月、Rollは適用外。欠損をゼロ埋めしない |
| Timeframes | D1、H4、H1、M30、M15 | 1mからの集計定義・境界を変更しない |
| Period split | train／validation／holdoutをexclusiveに分離 | holdoutを調整に再利用しない |
| Provider data cost | `0 USD`（公開Data costの記録） | 内部通信・保存・実行費、fee、slippageとは別物 |

## 6. P5非対象とP6への禁止された自動拡張

- Futures、Funding、Liquidation、Options、他のcrypto symbolを追加しない。
- 利益性、収益性、勝率、最適化、実Risk、実約定をP5 Evidenceから判定しない。
- Broker接続、Paper、Live、実資金、注文経路を作成・有効化しない。
- Cloud、P4 DB、Core、migrationを変更しない。
- API key／Secret値を読み取らず、HTML・ログ・Evidenceへ保存しない。
- 旧Databento／CME Evidence、P4 synthetic fixtureをBinanceの実市場Evidenceへ一般化しない。
