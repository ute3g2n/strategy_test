## 6. 採用・除外を判定する確認手順

以下は値や Secret を出力しない再監査コマンドである。

```powershell
# ECC 固定コミット
git -C third_party/everything-claude-code rev-parse HEAD

# Project AI 部品
Get-ChildItem .codex/orchestrators -File -Filter '*.json' | Select-Object -ExpandProperty BaseName
Get-ChildItem .codex/agents -File -Filter '*.json' | Select-Object -ExpandProperty BaseName
Get-ChildItem .codex/skills -Directory | Where-Object { Test-Path (Join-Path $_.FullName 'SKILL.md') } | Select-Object -ExpandProperty Name

# 導入済みユーザー Skill（値ではなく存在だけ）
$names = 'python-patterns','python-testing','tdd-workflow','verification-loop',
  'coding-standards','security-review','agent-introspection-debugging',
  'ai-regression-testing','e2e-testing','eval-harness','agent-self-evaluation',
  'continuous-agent-loop','autonomous-loops','workspace-surface-audit',
  'llm-trading-agent-security'
$names | ForEach-Object {
  $skillPath = Join-Path 'C:\Users\ute3g\.codex\skills' (Join-Path $_ 'SKILL.md')
  [pscustomobject]@{name=$_; installed=(Test-Path $skillPath)}
}

# MCP／LSP は存在と section 名だけ
Test-Path .mcp.json
Test-Path .lsp.json
Select-String '^\[mcp_servers\.' C:\Users\ute3g\.codex\config.toml

# Secret 値を出さず、変数名だけ確認
Get-ChildItem -Force -File -Filter '.env*' | ForEach-Object {
  Get-Content $_.FullName | ForEach-Object {
    if($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*='){ $Matches[1] }
  }
}
```

## 7. 次回更新時の停止条件

次のいずれかを検出したら、自動導入・自動実行を停止し、差分と Human Gate を作る。

- ECC の固定コミットが台帳と異なる。
- Skill がネットワーク取得、資格情報、ファイル外の書込み、破壊的コマンドを要求する。
- Hook／MCP が未固定パッケージまたは認証情報を要求する。
- Agent／Orchestrator 名が既存名と衝突する。
- `default_orchestrator`、Phase 1 凍結部品、取引安全の fail-closed 条件を変更しようとする。
