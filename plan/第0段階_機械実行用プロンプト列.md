# 第0段階 機械実行用プロンプト列

この文書は、AIエージェントへ順番に投入できるプロンプト列である。すべて日本語で記述し、出力先も日本語ファイル名に統一する。

## 共通実行ヘッダー

```text
ステップID: <ステップID>
ロール: <ロール名>
タスク:
指定された入力を読み、指定された成果物を作成してください。
ルール:
- UnknownをPassにしない。
- 公式一次情報を優先する。
- Stable ID、URL、日付は追跡性のため維持する。
- 出力ファイル名、見出し、列名、説明文は日本語にする。
- Human Gateが必要な場合は、承認依頼文を作成して停止する。
```

## P08 構造スコア

```text
ステップID: P08
ロール: 構造スコア分析者
タスク:
H2承認済み候補とP07データベンダー調査結果を使い、Backtest前の構造スコアを作成してください。Backtest結果や過去収益率は使わず、執行・流動性、小口資金適合性、Access・運用、データ品質・費用、分散価値、Trend頑健性の6項目で暫定採点してください。
ルール:
- UnknownをPassにしない。
- 証拠不足の候補は除外せず、採点確信度を下げて保持する。
- 候補別パラメータ最適化をしない。
- 採点は優先深掘り順を作るための暫定評価であり、取引可否の確定ではない。
出力:
- research/asset_selection/08_構造スコア/08_スコアリングルール_v0.1_2026-08-02.md
- research/asset_selection/08_構造スコア/08_構造スコア表_v0.1_2026-08-02.csv
```
