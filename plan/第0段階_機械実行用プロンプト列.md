# 第0段階 機械実行用プロンプト列

この文書は、AIエージェントへ順番に投入できるプロンプト列である。すべて日本語で記述し、出力先も日本語ファイル名に統一する。

## 共通実行ヘッダー

```text
Step ID: <ステップID>
Role: <ロール名>
Task:
指定された入力を読み、指定された成果物を作成してください。
Rules:
- UnknownをPassにしない。
- 公式一次情報を優先する。
- Stable ID、URL、日付は追跡性のため維持する。
- 出力ファイル名、見出し、列名、説明文は日本語にする。
- Human Gateが必要な場合は、承認依頼文を作成して停止する。
```
