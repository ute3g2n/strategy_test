# タートルズ・トレンドフォロー戦略  
## 原典ルール、数式、実装仕様、現代市場への適用に関する体系的レポート

> **注意**：本レポートは投資助言ではなく、歴史的取引システムの研究・実装資料です。先物取引では、証拠金を超える損失、ギャップ、流動性枯渇、追証、限月交代などのリスクがあります。

---

## エグゼクティブ・サマリー

タートルズ戦略の本質は「20日または55日の高値・安値ブレイクアウト」そのものではありません。中核は次の組み合わせです。

1. **多数の流動性市場を一貫して取引する**
2. **ATRによって各市場のドル・リスクを正規化する**
3. **小さな損失を繰り返し受け入れ、少数の巨大トレンドを逃さない**
4. **含み益が増えた方向にだけ、0.5N刻みでポジションを追加する**
5. **単一市場・相関市場・ポートフォリオ方向別にリスク上限を設ける**
6. **裁量的な予測より、事前に定義した規則を優先する**

重要な誤解は、**「1 Unit＝損失リスク1%」ではない**点です。原典では、

- 1 Unitのポジションが **1N動いたときの損益 ≒ 口座資金の1%**
- 初期ストップは通常2N
- したがって初期1 Unitのストップ損失は、スリッページ前で約2%

となります。さらに4 Unitまで積み増した場合、全Unitを共通ストップまで保有したときの合計リスクは、理想的な0.5N間隔なら約5%になります。

本レポートの中心資料は、オリジナル・タートルのCurtis Faithが公開した『The Original Turtle Trading Rules』です。同資料は、ルールを市場、ポジションサイジング、エントリー、ストップ、エグジット、執行に分けて記述しています。もっとも、これは当時の授業資料そのものではなく、元参加者による後年の再構成資料である点には留意が必要です。

---

# 1. タートルズ戦略の背景と基本哲学

## 1.1 リチャード・デニスとウィリアム・エックハルトの実験

1983年、商品先物トレーダーのリチャード・デニスとウィリアム・エックハルトは、「優秀なトレーダーは生まれつきなのか、それとも教育によって作れるのか」を巡って議論しました。

デニスは「明確なルールを教えれば、取引経験のない人でも成功できる」と考え、エックハルトは適性や生得的能力を重視していました。そこで一般公募を行い、1,000人以上の応募者から候補を絞り込み、最初のグループには13人が参加しました。1983年12月末に約2週間の訓練を行い、1984年初頭から実資金で取引させました。最初は小規模口座でルール遵守を確認し、その後、多くの参加者に50万～200万ドル規模の資金が割り当てられました。

「タートル」という名称は、デニスがシンガポールの養殖場を見た後、「カメを育てるようにトレーダーを育てる」と表現したことに由来すると、1989年のWall Street Journalの記事および原典ルール集に記録されています。

参加者数や利益総額については、最初のグループだけを数えるか、後続グループを含めるかによって資料ごとの差があります。そのため、「13人」「14人」「23人」など複数の数字が流通しています。

---

## 1.2 トレンドフォローの根本思想

### 「市場を予測しない」の正確な意味

タートルズは、経済指標やニュースから裁量的に相場の方向を予想するのではなく、**価格が実際に一定期間のレンジを突破した後に反応する**方式を採用しました。

ただし、これは統計的な意味で予測を全くしていないわけではありません。システムには、

> 過去20日または55日のレンジを突破した価格は、その方向にしばらく持続する可能性がある

という条件付き仮説が内在しています。

したがって正確には、

- 価格目標を予想しない
- トレンドの長さを予想しない
- 天井・底を当てようとしない
- ブレイクアウトが成功するかを個別判断しない
- 事前ルールに従って参加し、失敗したら機械的に撤退する

という思想です。

原典では、完全なトレーディングシステムは少なくとも以下を定義すべきだとされています。

| 構成要素 | 問い |
|---|---|
| 市場選択 | 何を取引するか |
| ポジションサイズ | どれだけ買う・売るか |
| エントリー | いつ参入するか |
| ストップ | 損失ポジションからいつ撤退するか |
| エグジット | 利益ポジションをいつ手仕舞うか |
| 執行 | どのように注文するか |

原典が特に強調するのは、優れたルールを知っていることより、連敗中もシグナルを取り続ける規律です。

# 2. 対象市場と選定基準（What to Trade）

## 2.1 当時の取引対象

タートルズは、主としてシカゴとニューヨークの取引所に上場する**流動性の高い先物**を取引しました。

| 資産クラス | 主な市場 |
|---|---|
| 金利 | 米国30年国債、10年国債、90日T-Bill、Eurodollar |
| 通貨 | スイスフラン、ドイツマルク、英ポンド、仏フラン、日本円、カナダドル |
| 株価指数 | S&P 500指数先物 |
| 貴金属・工業金属 | 金、銀、銅 |
| エネルギー | 原油、ヒーティングオイル、無鉛ガソリン |
| ソフトコモディティ | コーヒー、ココア、砂糖、綿花 |

穀物が除外された主因は、デニス自身の取引によって取引所のポジション上限に近づいていたためです。食肉先物は、当時の取引ピットにおける価格操作・腐敗への懸念から除外されました。したがって、「穀物や食肉はトレンドが出ないから除外された」という理解は正確ではありません。

市場を除外する裁量は認められていましたが、ある市場を取引しないと決めた場合、都合のよい時だけ参加することは禁止されていました。これは、**市場選択による後知恵バイアスを防ぐ**ための重要な規則です。

---

## 2.2 現代市場での必須条件

現代版タートル戦略では、単に「値動きが大きい銘柄」を選ぶべきではありません。以下の条件が必要です。

### 必須条件1：十分な流動性

原典では流動性が最優先基準でした。大口注文によって自ら価格を動かす市場では、理論上のブレイクアウト価格で約定できないからです。

実務上の研究基準としては、例えば次を使用できます。

- 予定注文数量が平均日次出来高の1%以下
- 総保有数量が建玉残高の1%以下
- 予想往復コストが0.05～0.10N以下
- 通常時のスプレッドが0.5N追加幅の10%以下
- ストップ時に複数ティックの板が存在する

これらは原典の固定数値ではなく、現代のバックテストに用いる保守的な初期基準です。

### 必須条件2：ロング・ショート双方を実行できること

タートルズ戦略は上昇相場だけでなく、下落トレンドをショートで取る設計です。

現物株に適用する場合には、

- 空売り規制
- 貸株料
- 銘柄別の売り禁
- 配当調整
- 上場廃止バイアス

を考慮する必要があります。

ETFのロングだけで代用すると、原型とは異なる「ロング・フラット型」になります。

### 必須条件3：価格系列が連続的かつ検証可能であること

先物では、限月交代による価格差を処理する必要があります。

バックテストでは通常、

- シグナル計算：バックアジャスト済み連続先物
- 注文価格・損益計算：実際の限月価格
- ロール損益：実際の乗換価格差とコスト

を分離します。

連続先物上の人工的な価格ジャンプをブレイクアウトと誤認しない設計が必要です。

### 必須条件4：「トレンド性」をインサンプル成績だけで判定しない

過去に利益が出た銘柄だけを選ぶと、データマイニングになります。

適切な評価は、

- 20/10
- 55/20
- 100/50
- 200/100

など複数速度で検証し、

- 複数期間
- 複数資産クラス
- 手数料・スリッページ控除後
- ウォークフォワードまたは完全アウト・オブ・サンプル

で頑健性を確認することです。

# 3. ボラティリティとポジションサイジング  
## N値とUnit

## 3.1 True Range

タートルズは、通常の日中値幅だけでなく、前日終値からのギャップを含めるため、True Rangeを使用しました。

\[
TR_t=
\max
\left(
H_t-L_t,\;
|H_t-C_{t-1}|,\;
|L_t-C_{t-1}|
\right)
\]

- \(H_t\)：当日高値
- \(L_t\)：当日安値
- \(C_{t-1}\)：前日終値

原典の表記は絶対値を省略していますが、実装上は上式の絶対値形式が安全です。

---

## 3.2 Nの計算式

最初のNは、20日間のTRの単純平均です。

\[
N_{20}
=
\frac{1}{20}
\sum_{i=1}^{20}TR_i
\]

その後は、

\[
N_t
=
\frac{19N_{t-1}+TR_t}{20}
\]

と更新します。

これは平滑化係数を

\[
\alpha=\frac{1}{20}
\]

とするWilder型ATRです。

一般的なEMAの

\[
\alpha=\frac{2}{20+1}
\]

とは異なります。プログラムで通常のEMA(20)を使用すると、原型と違うNになります。TradingView等では、単純な`ema(TR,20)`ではなく、WilderのRMA/ATRに相当する関数を使用する必要があります。

---

## 3.3 1 Unitの定義

先物1枚あたり、価格が1ポイント変化したときのドル損益を \(V\) とします。

\[
\text{1契約の1Nドル変動}
=
N \times V
\]

1 Unitの契約数は、

\[
\text{Unit Size}
=
\left\lfloor
\frac{0.01A}{N\times V}
\right\rfloor
\]

- \(A\)：ポジション計算に使うNotional Account
- \(N\)：20日ATR
- \(V\)：1ポイント当たりのドル価値
- \(\lfloor\cdot\rfloor\)：端数切り捨て

したがって、

\[
\text{1 Unitが1N動いた損益}
\approx 1\%\times A
\]

となります。

### 重要

これは、

\[
\text{最大損失}=1\%
\]

という意味ではありません。

通常のストップは2Nなので、初期1 Unitの予定最大損失は、

\[
2N\times \text{Unit Size}\times V
\approx 2\%A
\]

です。

---

## 3.4 具体例：$100,000口座とMicro WTI原油先物

CMEのMicro WTI原油先物MCLは、

- 契約サイズ：100バレル
- 最小ティック：$0.01/バレル
- 1ティック価値：$1
- $1.00の価格変化：1契約当たり$100

です。

次を仮定します。

| 項目 | 数値 |
|---|---:|
| Notional Account | $100,000 |
| 1% | $1,000 |
| N | $1.20/バレル |
| 1ポイントのドル価値 | $100 |
| 1契約の1N変動 | $120 |

\[
\text{Unit Size}
=
\left\lfloor
\frac{1{,}000}{1.20\times100}
\right\rfloor
=
\lfloor8.333\rfloor
=
8\text{契約}
\]

したがって、

\[
1Nの実際のドルリスク
=
8\times1.20\times100
=
\$960
\]

\[
1Nの実際の口座比率
=
\frac{960}{100,000}
=
0.96\%
\]

2Nストップなら、

\[
8\times2.40\times100
=
\$1,920
\]

すなわち、初期1 Unitのストップリスクは約1.92%です。

---

## 3.5 小口資金の問題

契約数を整数に切り捨てるため、口座が小さいほどリスク正規化が粗くなります。

原典でも、100万ドル口座では16契約になる例が、10万ドル口座では1契約しか建てられず、分散効果が著しく低下すると説明されています。

現代では、Micro先物や小口CFDによって粒度を改善できますが、CFDには、

- 相対取引先リスク
- オーバーナイト金利
- 業者独自スプレッド
- 価格配信差

があります。

# 4. エントリー・ルール  
## System 1とSystem 2

## 4.1 ドンチアンチャネル

時点 \(t\) の直前 \(L\) 日間について、

\[
Upper_L(t)
=
\max(H_{t-1},H_{t-2},\ldots,H_{t-L})
\]

\[
Lower_L(t)
=
\min(L_{t-1},L_{t-2},\ldots,L_{t-L})
\]

とします。

**当日の高値・安値をチャネル計算に含めてはいけません。**  
含めるとルックアヘッド・バイアスになります。

---

## 4.2 System 1：20日ブレイクアウト

### ロング

\[
Price_t > Upper_{20}(t)
\]

より厳密には、原典では、

\[
Price_t \ge Upper_{20}(t)+1\text{ tick}
\]

で1 Unit買います。

### ショート

\[
Price_t < Lower_{20}(t)
\]

より厳密には、

\[
Price_t \le Lower_{20}(t)-1\text{ tick}
\]

で1 Unit売ります。

終値確定を待たず、日中に水準を突破した時点で参入します。寄付きがブレイクアウト水準を飛び越えた場合は、理論上のチャネル価格ではなく寄付き価格付近で参入します。

---

## 4.3 System 1の「前回勝ちトレード」フィルター

System 1では、直前のブレイクアウトが勝ちだった場合、次の20日ブレイクアウトを見送ります。

### 前回ブレイクアウトが「負け」と判定される条件

ブレイクアウト後、

1. 価格が仮想エントリーから2N逆行する
2. それが利益の出る10日チャネル・エグジットより先に起きる

場合、前回ブレイクアウトは負けです。

その場合、次の20日ブレイクアウトを取ります。

### 前回が勝ちだった場合

次の20日ブレイクアウトを無視し、55日ブレイクアウトまで待ちます。この55日水準を**Failsafe Breakout**と呼びます。

### 実装上の重要事項

「前回ブレイクアウト」とは、

- 実際に取引したブレイクアウト
- 前回勝ちのため見送ったブレイクアウト

の両方を含みます。

つまり、見送ったシグナルについても、仮想的に、

- 2Nストップに先に到達したか
- 利益となる10日出口に先に到達したか

を追跡しなければなりません。

また、前回の方向は関係ありません。

- 前回のロングが負け → 次のショート20日ブレイクアウトを取れる
- 前回のショートが負け → 次のロング20日ブレイクアウトを取れる

という設計です。

---

## 4.4 System 1の条件分岐

| 前回ブレイクアウト | 次の20日ブレイクアウト | 55日ブレイクアウト |
|---|---|---|
| 負け | 取る | 通常は20日で先に参加 |
| 勝ち | 見送る | Failsafeとして取る |
| 見送ったシグナル | 仮想結果を追跡 | 必要なら取る |

---

## 4.5 System 2：55日ブレイクアウト

### ロング

\[
Price_t \ge Upper_{55}(t)+1\text{ tick}
\]

で1 Unit買います。

### ショート

\[
Price_t \le Lower_{55}(t)-1\text{ tick}
\]

で1 Unit売ります。

System 2では、前回のブレイクアウトが勝ちか負けかを問わず、**すべての55日ブレイクアウトを取ります**。

原典では、資金配分について、

- System 2だけ
- System 1と2を50対50
- その他の比率

が認められていました。

---

# 5. ピラミッディング  
## 0.5Nごとの追加

初期1 Unitを建てた後、価格が有利な方向に0.5N進むごとに1 Unit追加します。

### ロング

直前の実際の約定価格を \(E_j\) とすると、

\[
E_{j+1}=E_j+0.5N
\]

### ショート

\[
E_{j+1}=E_j-0.5N
\]

最大4 Unitです。

基準は理論上のブレイクアウト価格ではなく、**直前Unitの実際の約定価格**です。

例えば、初回注文が0.5N不利にスリップした場合、2回目の追加水準は元のブレイクアウト価格から見て1N先になります。

---

## 5.1 MCLの例

前節の条件を使用します。

- N＝$1.20
- 0.5N＝$0.60
- 初回ロング約定＝$75.00
- 1 Unit＝8契約

| Unit | 追加価格 |
|---|---:|
| 1 | $75.00 |
| 2 | $75.60 |
| 3 | $76.20 |
| 4 | $76.80 |

急激な値動きの場合、原典では1日のうちに4 Unitすべてを追加することもありました。

---

## 5.2 Unit上限

原典のポートフォリオ制限は次のとおりです。

| リスク階層 | 上限 |
|---|---:|
| 単一市場 | 4 Units |
| 密接に相関する市場群 | 同一方向6 Units |
| 緩やかに相関する市場群 | 同一方向10 Units |
| ポートフォリオ全体の同一方向 | 12 Units |

密接な相関の例：

- 原油とヒーティングオイル
- 金と銀
- スイスフランとドイツマルク
- T-BillとEurodollar

緩やかな相関の例：

- 金と銅
- 銀と銅

です。

### 「全体で12 Unit」の正確な意味

12 Unitはグロス全体ではなく、**同一方向の上限**です。

理論上は、

- ロング12 Units
- ショート12 Units

を同時保有できるため、グロスでは24 Unitsになり得ます。ただし、各市場・相関グループの制限も同時に満たす必要があります。

---

# 6. リスク管理とストップロス

## 6.1 基本ストップ

### ロング

\[
Stop=Entry-2N
\]

### ショート

\[
Stop=Entry+2N
\]

1 Unitが1N動いたとき約1%の損益となるため、初期1 Unitの2Nストップは約2%のリスクです。

原典では、大口ポジションをブローカーに知られないよう、必ずしも取引所にストップ注文を置かず、価格到達時に成行または指値で決済する方式も採られていました。現代の個人・小規模運用者がこれを模倣すると、監視漏れや通信障害の危険があるため、通常はサーバー側ストップの方が安全です。

---

## 6.2 Unit追加時のストップ移動

追加Unitを0.5N上で建てたら、既存Unitのストップも0.5N引き上げます。

通常は、全Unitのストップを、

### ロング

\[
Stop=E_{\text{latest}}-2N
\]

### ショート

\[
Stop=E_{\text{latest}}+2N
\]

に揃えます。

MCLの例では、

| 状態 | 最新約定 | 共通ストップ |
|---|---:|---:|
| 1 Unit | $75.00 | $72.60 |
| 2 Units | $75.60 | $73.20 |
| 3 Units | $76.20 | $73.80 |
| 4 Units | $76.80 | $74.40 |

となります。

---

## 6.3 4 Unit保有時の実際のストップリスク

4 Unitを共通ストップ$74.40まで保有した場合：

| Unit | 建値 | 1契約当たり逆行幅 | 8契約の損失 |
|---|---:|---:|---:|
| 1 | $75.00 | $0.60 | $480 |
| 2 | $75.60 | $1.20 | $960 |
| 3 | $76.20 | $1.80 | $1,440 |
| 4 | $76.80 | $2.40 | $1,920 |
| **合計** |  |  | **$4,800** |

\[
\frac{4,800}{100,000}=4.8\%
\]

端数がない理論上は約5%です。

したがって、

> 「各トレードのリスクは常に2%以下」

という説明は、単独Unitについては概ね正しいものの、4 Unitに積み増した市場全体のストップリスクとしては正しくありません。

また、ギャップやスリッページが発生すれば5%を超える可能性があります。

---

## 6.4 ギャップ約定時

原典では、4番目のUnitが本来の0.5N間隔より高く約定した場合、そのUnitだけ別のストップ価格になる例が示されています。つまり、必ずしも全Unitが同一ストップになるとは限りません。

実装時には各Unitについて、

\[
Stop_i=Entry_i-2N
\]

をまず計算し、追加ごとのストップ引き上げを適用する方が安全です。

---

## 6.5 代替方式：Whipsaw Stop

原典には、より頻繁に損切りする代替方式も記載されています。

- ストップ幅：0.5N
- 1 Unit当たりリスク：約0.5%
- ストップ後、元のエントリー水準に再到達すれば再参入
- 各Unitのストップは個別に維持
- 4 Unit合計リスクは約2%

この方式は勝率が下がり、損切り回数が増えますが、一部のタートルは良好な成績を上げたとされています。

# 7. エグジット・ルール

## 7.1 System 1

### ロング

価格が直前10日間の安値を下抜いたら、全Unitを決済します。

\[
Price_t \le Lower_{10}(t)
\]

### ショート

価格が直前10日間の高値を上抜いたら、全Unitを決済します。

\[
Price_t \ge Upper_{10}(t)
\]

---

## 7.2 System 2

### ロング

\[
Price_t \le Lower_{20}(t)
\]

### ショート

\[
Price_t \ge Upper_{20}(t)
\]

到達したら全Unitを決済します。

---

## 7.3 ストップとエグジットの違い

| 種類 | 目的 |
|---|---|
| 2Nストップ | 初期失敗・急反転から資金を守る |
| 10日／20日出口 | 成功したトレンドが反転したときに利益ポジションを閉じる |

実際には、先に到達した方が有効です。

\[
Exit Price=
\text{先に到達した Hard Stop または Channel Exit}
\]

タートルズ型トレンドフォローでは、含み益のかなりの部分を返してから決済することがあります。原典も、10日・20日安値まで待つ過程で、含み益の20%、40%、場合によってはそれ以上が消えることを指摘しています。

これは欠陥というより、巨大トレンドを途中の押し戻しで手放さないための設計です。

# 8. ドローダウン対策  
## Notional Account

## 8.1 実残高とポジション計算資金を分離する

タートルズは、現在の実口座残高をそのままUnit計算に使用するのではなく、**Notional Account**というポジション計算用の基準額を設定していました。

原典の例では、

- 初期Notional Account：$1,000,000
- 10%の損失：$100,000
- Notional Accountを20%削減して$800,000
- さらに$800,000の10%＝$80,000を失う
- Notional Accountをさらに20%削減して$640,000

となります。

---

## 8.2 数式化

現在のNotional Accountを \(A_k\) とすると、

\[
A_{k+1}=0.8A_k
\]

各段階で追加損失が、

\[
0.1A_k
\]

に達したとき、次の縮小を行います。

したがって、

\[
A_k=A_0(0.8)^k
\]

です。

k回目の縮小までに必要な累積損失は、

\[
D_k
=
0.1\sum_{j=0}^{k-1}A_0(0.8)^j
\]

\[
D_k
=
0.5A_0\left(1-0.8^k\right)
\]

となります。

---

## 8.3 $100,000口座での例

| 累積状態 | 追加損失条件 | 次のNotional |
|---|---:|---:|
| 初期 | — | $100,000 |
| 第1縮小 | $10,000損失 | $80,000 |
| 第2縮小 | さらに$8,000、累計$18,000 | $64,000 |
| 第3縮小 | さらに$6,400、累計$24,400 | $51,200 |
| 第4縮小 | さらに$5,120、累計$29,520 | $40,960 |

Notionalが$80,000になれば、Unit計算の分子は、

\[
0.01\times80,000=\$800
\]

となるため、すべての新規ポジションが20%縮小します。

---

## 8.4 原典内の軽微な不整合

文章では「元の口座の10%下落ごと」と表現されていますが、数値例では2回目の基準を$800,000の10%である$80,000としています。

したがって、実装上は原典の数値例に従い、

> 現在のNotional Accountの10%を追加で失うごとに、Notionalを20%縮小する

と解釈するのが自然です。

回復については、原典は年初の基準エクイティに戻るまで縮小Notionalを使用するとしています。段階的に20%ずつ戻す方式は明文化されていません。

---

# 9. 現代市場における有効性と注意点

## 9.1 トレンドフォロー一般には長期的証拠がある

Moskowitz、Ooi、PedersenのJournal of Financial Economics論文は、株価指数、通貨、商品、債券の58の流動性先物・フォワードについて、自己の過去リターンが将来リターンを予測する「時系列モメンタム」を検出しました。特に1～12か月の持続性が観察され、それより長い期間では部分的な反転が見られました。

Hurst、Ooi、Pedersenは、データを1880年まで拡張した研究で、分散されたトレンドフォローが幅広い歴史的環境でプラスの平均収益を示したと報告しています。

Lempérièreらの研究も、商品、通貨、株価指数、債券における長期トレンド効果を確認する一方、短期的なトレンド効果は近年弱まっていると報告しています。

ただし、これらの研究が証明しているのは**トレンドフォローという戦略群**であり、20/55日ドンチアン、0.5N追加、2Nストップというタートルズの完全な組合せが、現在も同じ成績を出すことではありません。

---

## 9.2 現代の主な課題

### 1. レンジ相場での連続損失

ブレイクアウトの大半がトレンドにならない期間には、

- 高値で買って反落
- 安値で売って反発
- 再び高値を買う
- 再び安値を売る

というWhipsawが繰り返されます。

トレンドフォローは、勝率の高さではなく、

\[
\text{期待値}
=
P(W)\times Avg(W)
-
P(L)\times Avg(L)
\]

で成立します。

勝率が30～40%でも、平均利益が平均損失の数倍なら利益になります。

### 2. 取引コスト

20日System 1は55日System 2より売買回数が増えやすく、

- スプレッド
- 手数料
- スリッページ
- マーケットインパクト
- ロールコスト

の影響を強く受けます。

長期研究ではトレンド効果自体は確認されていますが、短期トレンドの弱体化も報告されているため、原型のSystem 1は特にコスト感応度を検証すべきです。

### 3. 「アルゴリズム取引がダマシを増やした」とは断定できない

高速取引や電子化によって単純な短期パターンが競争にさらされた可能性はあります。しかし、

> アルゴリズム取引の増加＝必ずブレイクアウトのダマシ増加

という因果関係は、確立した事実ではありません。

2026年のプレプリントでは、短期トレンドの劣化を、HFTだけでなく、ボラティリティ調整後のティックサイズや注文板構造との関係から説明しています。ただし、これは査読前研究であり、結論は暫定的です。

### 4. 相関は危機時に変化する

平常時に異なる市場でも、危機時には、

- 株安
- 債券売り
- ドル高
- 商品安

などが一つのマクロ要因で同時に動くことがあります。

過去の固定的な「金と銀」「原油とヒーティングオイル」という分類だけでは不十分です。

### 5. ギャップとストップ超過

2Nストップは損失を2Nに保証しません。

\[
実損失
=
予定ストップ損失
+
ギャップ
+
スリッページ
+
手数料
\]

です。

原典にも、1987年の急変時、金利先物の集中ポジションによって一部口座が1日で20～40%下落したとの記述があります。Unit上限は損失を軽減しましたが、完全には防げませんでした。

# 10. 現代風にモダナイズする一般的な方法

以下は「原型の再現」ではなく、現代向けの研究候補です。

## 10.1 1 Unitリスクを下げる

原型：

\[
1N\text{リスク}=1\%
\]

現代的な保守案：

\[
1N\text{リスク}=0.25\%\sim0.50\%
\]

例えば0.5%なら、

\[
Unit=
\left\lfloor
\frac{0.005A}{N\times V}
\right\rfloor
\]

です。

4 Unit積み増し後の理論ストップリスクも、約5%から約2.5%に低下します。

---

## 10.2 複数速度のアンサンブル

単一の20日・55日だけでなく、

| 速度 | エントリー／エグジット例 |
|---|---|
| 短期 | 20／10 |
| 中期 | 55／20 |
| 中長期 | 100／50 |
| 長期 | 200／100 |

にリスクを分散します。

例えば各速度に25%ずつ配分すれば、特定のルックバック期間への依存を減らせます。

長期研究では、異なる時間軸の時系列モメンタムを組み合わせる方式が一般的です。

---

## 10.3 動的相関管理

過去60～120営業日のリターンから相関行列を計算します。

\[
\Sigma_t
=
Cov(r_{t-L+1},\ldots,r_t)
\]

ポートフォリオの予測ボラティリティは、

\[
\sigma_p
=
\sqrt{w^\top \Sigma_t w}\sqrt{252}
\]

です。

目標年率ボラティリティを \(\sigma^*\) とすると、

\[
Scale_t
=
\min\left(
1,\frac{\sigma^*}{\sigma_p}
\right)
\]

によって全ポジションを縮小できます。

固定的な6／10／12 Unit上限と併用し、

- エネルギー
- 貴金属
- 株価指数
- 金利
- 通貨

ごとにリスク上限を設定する方法が一般的です。

---

## 10.4 コストを考慮したエントリーバッファー

単純な1ティック突破ではなく、

\[
Long Trigger
=
Upper_L+\max(1\text{ tick},bN)
\]

\[
Short Trigger
=
Lower_L-\max(1\text{ tick},bN)
\]

とする方法があります。

\(b\) は、例えば0.05～0.15程度を検証します。

ただし、バッファーを広げるほど、

- ダマシは減る
- 参入は遅れる
- 大きなギャップを追いかける
- 利益幅が減る

というトレードオフがあります。

---

## 10.5 ポートフォリオ・ボラティリティ・ターゲット

原型はUnit数を制限しますが、現在ではポートフォリオ全体を、

- 年率8%
- 年率10%
- 年率12%
- 年率15%

などの目標変動率に合わせる方式が一般的です。

ただし、過去ボラティリティが低い局面でレバレッジが過大にならないよう、

\[
Scale_t
=
\min(Scale_{\max},\sigma^*/\sigma_p)
\]

とし、絶対レバレッジ上限も設けるべきです。

---

## 10.6 ボラティリティ急上昇への対応

Nは過去データの平均なので、急激なボラティリティ上昇に遅れます。

対策例：

- 短期ATRと長期ATRの大きい方を採用
- 当日TRが過去Nの3倍以上なら新規追加を停止
- 市場ボラティリティが一定水準を超えたら全体を縮小
- ギャップ時の追加Unitを禁止
- ストップ到達不能市場への新規参入を停止

例えば、

\[
N_{\text{risk}}
=
\max(ATR_{20},ATR_{60})
\]

とすると、直近20日だけが異常に低ボラだった場合の過大ポジションを抑えられます。

# 11. 実装用ルールセット

## 11.1 毎日引け後に計算

各市場について、

1. \(TR_t\)
2. \(N_t\)
3. 20日高値・安値
4. 55日高値・安値
5. 10日高値・安値
6. 20日出口水準
7. Unit Size
8. 相関グループの現在Unit数
9. ポートフォリオのロング・ショートUnit数

を更新します。

---

## 11.2 ポジションなしの場合

### System 1

```text
if 価格 >= 前20日高値 + 1tick:
    if 前回ブレイクアウトが負け:
        1 Unit買い
    else:
        20日シグナルを見送り
        55日Failsafeを待つ

if 価格 <= 前20日安値 - 1tick:
    if 前回ブレイクアウトが負け:
        1 Unit売り
    else:
        20日シグナルを見送り
        55日Failsafeを待つ
```

### System 2

```text
if 価格 >= 前55日高値 + 1tick:
    1 Unit買い

if 価格 <= 前55日安値 - 1tick:
    1 Unit売り
```

---

## 11.3 ポジションありの場合

```text
if ハードストップ到達:
    全該当Unitを決済

else if チャネル出口到達:
    全Unitを決済

else if 価格が直前約定から有利に0.5N進み、
        単一市場・相関群・方向別上限を超えない:
    1 Unit追加
    既存ストップを0.5N移動
```

---

## 11.4 日足バックテストの注意

同じ日足の中で、

- 追加水準
- ストップ
- チャネル出口

の複数がヒットした場合、OHLCだけでは順序が分かりません。

対策は、

1. 分足・ティックデータを使用する
2. 不明時は不利な順序を採用する
3. 当日追加したUnitが同日ストップされる可能性を反映する

のいずれかです。

有利な順序を無条件に選ぶと、重大なルックアヘッド・バイアスになります。

# 12. 総合評価

## 原型のまま残す価値が高い部分

- 価格ベースの客観的シグナル
- ボラティリティによるポジション正規化
- 利益方向だけへのピラミッディング
- 単一市場と相関市場の上限制限
- 損失時の自動ダウンサイズ
- 多市場分散
- すべてのシグナルを一貫して取る規律

## 現代では再検討すべき部分

- 1N＝口座の1%という攻撃的なUnit
- 静的な相関グループ
- 20日System 1のコスト感応度
- 1ティックだけのブレイクアウト確認
- 日中監視による手動ストップ
- 限月交代・ロール処理の不足
- ポートフォリオ全体の予測ボラティリティ管理不足
- ギャップ・流動性枯渇・サーキットブレーカーへの対応

## 最終結論

タートルズ戦略は、単純なブレイクアウト手法ではなく、

\[
\boxed{
\text{トレンド検出}
+
\text{ボラティリティ調整}
+
\text{非対称損益}
+
\text{多市場分散}
+
\text{機械的資金管理}
}
\]

からなる統合システムです。

現代でも有効性が期待できるのは、20日・55日という特定の数字ではなく、

- 価格が持続的に動く局面を捕捉する
- 事前に損失幅を限定する
- 市場間のリスクを均等化する
- 小さな損失を多数受け入れる
- 巨大トレンドを途中で利益確定しない

という構造です。

その一方で、原型の1% Unitをそのまま使うと、4 Unit積み増し、相関市場への集中、ギャップを通じて、想像以上に大きなドローダウンが発生し得ます。現代に適用する場合は、**0.25～0.5% Unit、動的相関管理、複数時間軸、ポートフォリオ・ボラティリティ・ターゲット、現実的なコストモデル**を組み合わせるのが合理的です。
