# 01 調査憲章 v0.1

## 調査目的

タートルズ・トレンドフォロー戦略を現代の自動売買システムに適用する前提で、取引候補となる資産を選定する。最終的には30から50件程度の候補を残し、初期運用では3から5件へ絞る。

## 評価単位

候補は `エクスポージャー × 取引手段 × Broker/Venue` の組合せで評価する。

## 対象資産クラス

- 株価指数
- 金利・債券
- 為替
- エネルギー
- 金属
- 穀物・油糧種子
- ソフトコモディティ
- 畜産
- ボラティリティ
- 暗号資産先物
- 環境・電力
- 不動産指数

## 対象外または別Track

ETF、CFD、スポットFX、暗号資産現物・無期限先物は、税務、API、取引コスト、相対取引先リスクが先物と大きく異なるため、必要時に別Trackで扱う。

## Hard Gate G1からG10

| Gate | 日本語名 | 通過条件 |
|---|---|---|
| G1 | 日本居住者・Broker利用可否 | 日本居住者が対象Brokerで取引できる |
| G2 | API | 発注、注文確認、ポジション確認、口座確認がAPIで可能 |
| G3 | Long/Short | LongとShortまたは同等の売買が可能 |
| G4 | 契約仕様 | 倍率、ティック、限月、受渡・決済が確認できる |
| G5 | 小口資金適合性 | 50万、75万、100万円でリスク計算できる |
| G6 | 流動性・スプレッド | 十分な出来高、建玉、スプレッドがある |
| G7 | データ | 履歴データとリアルタイムデータの取得方法がある |
| G8 | 運用リスク | ロール、受渡、Funding、Counterpartyを管理できる |
| G9 | 規制・税務メモ | 重要な規制・税務上の注意を記録する |
| G10 | Bias・データ完全性 | Survivorship bias、Look-ahead biasを管理できる |

## Bias対策

- Backtest結果で候補を作らない。
- 候補別にパラメータ最適化しない。
- UnknownをPassにしない。
- 公式一次情報を優先する。
- 情報の確認日と再確認期限を記録する。
