## 状態値

| 値 | 意味 |
|---|---|
| 通過 | Gateを通過した |
| 不通過 | Gateで除外する |
| 条件付き | 条件付きで次工程へ進める |
| 証拠不足 | 重要情報が不足している |
| 研究のみ | 研究対象にはできるが実運用候補ではない |
| 不明 | 判断に必要な情報がない |

## Unknown / 証拠不足 / 矛盾の扱い

| 状態 | 扱い |
|---|---|
| Unknown | 重要Gateでは通過扱いにしない |
| 証拠不足 | 追加調査対象として、必要な情報源と期限を記録する |
| 軽微な矛盾 | 判断への影響が小さい場合のみ条件付きで継続できる |
| 重大な矛盾 | Gate判断が変わる可能性があるため保留する |
| 未解決 | 解決するまで次の重要Gateへ進まない |

## Human Gate

| Gate | 承認対象 | 未承認時に止める作業 |
|---|---|---|
| H0 | 調査範囲、Hard Gate、Scorecard、Bias対策 | Webロングリスト調査 |
| H1 | ロングリストの網羅性、重複、情報源方針 | 詳細証拠検証 |
| H2 | Hard Gate除外、資金閾値、データ予算 | データ購入、詳細データ取得 |
| H3 | バックテスト手順、Holdout、試行回数 | 頑健性バックテスト |
| H4 | 30から50件の候補、監査結果、例外 | 最終選定 |
| H5 | 初期3から5件、費用、未解決事項 | 実装・Paper準備 |
