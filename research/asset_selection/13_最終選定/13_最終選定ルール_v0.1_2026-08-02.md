# P13 最終選定ルール

作成日: 2026-08-02  
対象工程: Phase 0 / P13  
位置づけ: アセット選定フェーズの最終整理。実取引開始承認ではない。

## 1. 目的

P08の構造スコア、P10の研究用データ確認、P12のレッドチーム監査を統合し、次の設計フェーズへ渡す取引アセット候補を確定する。

この「確定」は、実運用で取引する銘柄を最終決定する意味ではない。次フェーズで、システム構成、Broker接続、データ取得、バックテスト本実装、Paper Tradingを進めるための調査対象を凍結する意味である。

## 2. 判定分類

| 分類 | 意味 |
|---|---|
| 初期検証候補_本線 | Phase 1以降で最初に詳細確認・本実装バックテストへ進める候補 |
| 初期検証候補_条件付き | 重要な不確定事項が残るが、価値が高いため条件付きで残す候補 |
| 追加調査候補 | 最終30件に残すが、初期検証候補より後に確認する候補 |
| Fallback候補 | 同一Exposureのマイクロ候補が使えない場合の代替候補 |
| 別トラック | 本線から外し、Broker・規制・税務・別データの個別調査に分離する候補 |

## 3. P13選定ルール

1. P10のバックテスト損益は採用順位に使わない。
2. P12でFail候補になったBTC/MBTは本線最終30件から外す。
3. P12で重大PendingになったETH/METは、本線最終30件から外し、暗号資産先物別トラックへ分離する。
4. 暗号資産4件を外した穴は、P08の中確信度候補から分散価値の高い次点候補で補う。
5. 米国株指数の標準先物を追加して数合わせすることは避ける。理由は、既にMicro米国株指数4件が入っており、相関集中を強めるためである。
6. Micro穀物3件は、履歴期間・流動性・IBKR/IBSJ取扱確認を条件に、初期検証候補として残す。
7. 標準先物群は、同一ExposureのMicro候補が使えない場合のFallbackとして扱う。

## 4. 暗号資産先物の扱い

BTC、MBT、ETH、METは、CME商品としては存在する。しかし、IBKR/IBSJを前提に日本居住者がAPI自動売買する候補としては、居住地制約・取引権限・規制・税務の不確実性が大きい。

そのためP13では、本線最終30件から外し、別トラックへ分離する。

別トラックでは、必要に応じて次を調査する。

- 日本居住者が取引可能なBroker。
- API対応。
- 証拠金、最小数量、取引制限。
- 税務・規制上の扱い。
- 先物ではなくETF、CFD、現物、無期限先物を使う場合の別設計。

## 5. H5承認の意味

H5は、Phase 0のアセット選定結果を凍結し、次フェーズのシステム設計・本実装バックテスト設計へ進む承認である。

H5は、実運用開始の承認ではない。
