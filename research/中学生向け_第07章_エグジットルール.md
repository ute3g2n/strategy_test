# 第7章 エグジット・ルール

## この章でわかること

- エグジットとは、取引を終えることです。
- タートルズは、利益が出ている取引でも、ルールに従って終わらせました。
- System 1とSystem 2では、エグジットに使う日数が違います。
- ストップロスとエグジットは似ていますが、役割が違います。
- トレンドフォローでは、含み益をかなり返してしまうことがあります。

## まず一言でいうと

第7章は、「いつ取引を終えるか」の話です。

第6章では、損が大きくなりすぎないようにするストップロスを学びました。第7章では、利益が出ている取引も含めて、「どこで終了するか」を学びます。

トレンドフォローでは、値段が伸びているあいだは、できるだけ長くついていきます。でも、トレンドが弱くなったら終わります。

## エグジットとは何か

エグジットとは、取引を終えることです。

買っていたものを売って終える場合も、売りから入っていたものを買い戻して終える場合も、どちらもエグジットです。

大事なのは、「利益が出ているから、なんとなく終わる」ではなく、「決めたルールに当てはまったら終わる」という点です。

タートルズは、気分や予想で取引を終えるのではなく、価格が決められたラインを抜けたら終える、という考え方を使いました。

## System 1のエグジット

System 1では、比較的短い期間の値動きを見てエグジットします。

買いで入っている場合は、価格が直近10日間の安値を下回ったら取引を終えます。

売りで入っている場合は、価格が直近10日間の高値を上回ったら取引を終えます。

たとえば、上がると思って買っていたのに、最近10日間の中で一番弱いところをさらに下に抜けたら、「上昇の勢いがかなり弱くなった」と考えて終わるわけです。

逆に、下がると思って売っていたのに、最近10日間の中で一番強いところをさらに上に抜けたら、「下落の勢いが崩れた」と考えて終わります。

## System 2のエグジット

System 2では、System 1より長い期間を見てエグジットします。

買いで入っている場合は、価格が直近20日間の安値を下回ったら取引を終えます。

売りで入っている場合は、価格が直近20日間の高値を上回ったら取引を終えます。

20日間を見るので、System 1よりもゆっくり判断します。小さな上下では終わりにくく、大きなトレンドに長く乗りやすくなります。

その代わり、トレンドが終わりかけても、すぐには降りないことがあります。だから、利益をかなり返してからエグジットすることもあります。

## ストップロスとエグジットの違い

ストップロスとエグジットは、どちらも取引を終えるルールです。でも、役割が違います。

ストップロスは、取引を始めたあと、思った方向と逆に動いたときの非常ブレーキです。大きな損を防ぐために使います。

エグジットは、トレンドについていったあと、「もう勢いがなくなったかもしれない」と判断して終えるためのルールです。利益が出ている取引でも使います。

つまり、ストップロスは「失敗した取引から早く逃げるための出口」、エグジットは「トレンドが終わりそうな取引から降りるための出口」です。

第8章で出てくるドローダウンは、さらに別の考え方です。ドローダウンは1つの取引の出口ではなく、口座全体がどれくらい落ち込んだかを見るものです。

## どちらが先に来ても従う

タートルズでは、ストップロスとエグジットの両方を見ます。

もし価格がストップロスのラインに先に届いたら、そこで終わります。

もしストップロスには届かず、エグジットのラインに先に届いたら、そこで終わります。

大事なのは、「どちらのルールが先に発動したか」です。都合のよいほうを選ぶのではありません。

## 利益をかなり返すことがある

トレンドフォローでは、含み益をかなり返してしまうことがあります。

含み益とは、まだ確定していない利益のことです。たとえば、途中では大きく勝っていたのに、エグジットの合図が出るまで待っているうちに、その利益が小さくなることがあります。

原文では、20パーセント、40パーセント、あるいはそれ以上の含み益を返してしまうこともある、と説明されています。

これは聞くとかなり怖いです。でも、タートルズの考え方では、これは欠点というより、トレンドフォローの性質です。

なぜなら、早く利益確定しすぎると、本当に大きなトレンドを途中で降りてしまうからです。

小さな利益を守ることを優先しすぎると、何か月も続く大きな流れに乗れなくなります。だから、タートルズは「多少利益を返しても、大きなトレンドを取りに行く」設計にしていました。

## たとえ話で考える

エグジットは、電車に乗っているときの「降りる駅」に似ています。

ストップロスは、電車が反対方向へ走り出したときにすぐ降りる非常判断です。

エグジットは、目的地に近づいたり、行き先が変わりそうになったりしたときに降りる判断です。

トレンドフォローでは、途中の小さな駅で降りず、なるべく遠くまで乗ろうとします。そのかわり、終点の手前で少し戻ってから降りることもあります。

## この章のまとめ

第7章の中心は、「利益が出ている取引をどう終えるか」です。

System 1は直近10日間、System 2は直近20日間の値動きを使って、トレンドが崩れたかどうかを見ます。

ストップロスは損を大きくしないための非常ブレーキで、エグジットはトレンドが終わりそうなときに降りるためのルールです。

タートルズのやり方では、利益をかなり返してしまうことがあります。それでも、大きなトレンドを途中で降りないために、このようなルールになっています。

この文章は戦略の仕組みを説明するためのもので、実際の取引をすすめるものではありません。
