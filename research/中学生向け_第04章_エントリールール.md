# 第4章 エントリー・ルール

## この章でわかること

- エントリーが「取引を始める合図」であること
- 売りから入るとは何か
- ドンチアンチャネルが、過去の高値と安値の範囲を見る道具であること
- System 1は20日、System 2は55日の範囲を使うこと
- System 1には、前回の結果によって見送るルールがあること
- System 2は、前回の勝ち負けに関係なく合図を取ること
- 見送った合図も記録する必要があること

## まず一言でいうと

この章は、「値段が今までの範囲の外に抜けたら、取引を始める」というルールを説明しています。

タートルズは、ニュースを見て予想するのではありません。

値段が実際に大きく動いたことを合図にしました。

## やさしい解説

### エントリーとは何か

エントリーとは、取引を始めることです。

買いで入ることもあります。

これは、あとで高く売ることを考えて買う入り方です。

反対に、売りから入ることもあります。

売りから入るとは、値段が下がる動きに合わせて取引を始めることです。

ふつうの買い物の「先に買う」とは少し違います。

取引の世界では、先に売る形で始める方法もあります。

タートルズは、「そろそろ上がりそう」「そろそろ下がりそう」という気分では入りません。

先に決めたルールに合ったときだけ入ります。

### ドンチアンチャネルとは何か

ドンチアンチャネルは、過去何日かの高値と安値の範囲を見る考え方です。

たとえば、前の20日間で一番高かった値段を見ます。

同じように、前の20日間で一番安かった値段も見ます。

その間を、値段の通り道のように考えます。

値段がその上側を抜けたら、「上に強く動き始めたかもしれない」と見ます。

値段がその下側を抜けたら、「下に強く動き始めたかもしれない」と見ます。

ここで大事なのは、今日の高値や安値を、その範囲作りに入れないことです。

今日の値段を入れてしまうと、「答えを見てから問題を解く」ようなことになります。

過去のデータで試すとき、これをルックアヘッド・バイアスと呼びます。

ルックアヘッド・バイアスとは、まだ知らないはずの未来の情報を使ってしまう間違いです。

バックテストとは、過去のデータを使って、ルールがどう動いたかを試すことです。

だから、未来を知っていたような形で試してはいけません。

### 日中と終値の違い

日中とは、市場が開いていて、値段が動いている時間のことです。

終値とは、その日の取引が終わったときの値段です。

タートルズのエントリーは、終値まで待つとは限りません。

日中に合図の水準を抜けたら、その時点で入ります。

そのため、終値だけのデータで試すと、実際の順番とずれることがあります。

たとえば、日中に先に合図が出て、そのあと終値では戻っている場合があります。

この違いは、バックテストではとても大事です。

### System 1は20日ブレイクアウト

System 1は、前の20日間の範囲を使います。

ブレイクアウトとは、今までの値動きの範囲を外に抜けることです。

前の20日間で一番高かった値段を、少し上に抜けたら買います。

前の20日間で一番安かった値段を、少し下に抜けたら売ります。

原典では、ぴったり同じ値段ではなく、1ティックぶん外に抜けたら合図とします。

1ティックとは、その市場で動ける最小の値段の幅です。

もし朝の始まり値段が、すでに合図の水準を飛び越えていたら、理想の水準ではなく、その始まり値段の近くで入ることになります。

### System 1には見送りルールがある

System 1には、少し変わったルールがあります。

前回の20日ブレイクアウトが勝ちだった場合、次の20日ブレイクアウトは見送ります。

この場合、20日シグナルは取りません。

そして、55日Failsafe Breakoutを待ちます。

なぜなら、同じような短い合図を何度も追いかけると、無駄な取引が増えることがあるからです。

では、前回が負けだったらどうするのでしょうか。

その場合は、次の20日ブレイクアウトを取ります。

ここでいう負けとは、仮に入ったあと、利益の出る10日チャネル出口より先に、決められた損切りラインへ到達した場合です。

つまり、先に損切りの線へ行ったら、その合図は失敗と見ます。

細かい計算を覚える必要はありません。

大事なのは、次のことです。

前回の20日合図が失敗していたら、次の20日合図は取ります。

前回の20日合図が成功していたら、次の20日合図は見送ります。

### 見送った合図も記録する

実装では、ここがややこしい点です。

「前回のブレイクアウト」には、実際に取引した合図だけでなく、見送った合図も含まれます。

つまり、見送ったとしても、「もし入っていたら勝ちだったか、負けだったか」を仮に追いかけます。

たとえば、前回の20日買い合図が勝ちだったとします。

すると、次の20日売り合図は見送ります。

でも、その売り合図を記録から消してはいけません。

もし売りで入っていたら、10日チャネル出口より先に損切りラインへ行ったかを見ます。

もし先に損切りラインへ行ったなら、その見送った売り合図は負けとして記録します。

すると、その次の20日合図は取れるようになります。

これは、ゲームで「今回は参加しなかったけれど、参加していたらどうなったか」を記録しておくようなものです。

また、前回が買いだったか売りだったかは関係ありません。

前回の買い合図が負けなら、次の売り合図を取れます。

前回の売り合図が負けなら、次の買い合図を取れます。

### System 2は55日ブレイクアウト

System 2は、前の55日間の範囲を使います。

前の55日間で一番高かった値段を、少し上に抜けたら買います。

前の55日間で一番安かった値段を、少し下に抜けたら売ります。

System 2では、前回の合図が勝ちだったか負けだったかを気にしません。

すべての55日ブレイクアウトを取ります。

これは、System 1よりも長い期間を見る、より大きな合図です。

System 1で見送ったあとでも、55日ブレイクアウトが出たら入ることがあります。

この安全用の大きな合図は、Failsafe Breakoutと呼ばれます。

Failsafeとは、失敗に備える安全策という意味です。

### System 1とSystem 2の使い方

原典では、System 1とSystem 2の使い方にいくつかの形がありました。

System 2だけを使う形もありました。

System 1とSystem 2を半分ずつ使う形もありました。

ほかの割合にすることも認められていました。

ここで大事なのは、どの形がよいかをすすめることではありません。

タートルズのルールには、複数の使い方があったと理解することです。

## たとえ話

このルールは、校庭のラインを超えたかどうかを見る場面に似ています。

ボールがラインの内側にある間は、まだ様子見です。

ボールがラインをはっきり外に出たら、「外に出た」と判定します。

タートルズのブレイクアウトも同じです。

値段が、前の20日や55日の範囲をはっきり外に出たら、取引を始める合図になります。

ただし、あとから今日の動きを範囲に入れてはいけません。

それは、試合が終わってからラインを動かすようなものです。

## 気をつけること

この章は、取引をすすめる話ではありません。

昔の取引ルールをわかりやすく説明しているだけです。

ブレイクアウトは、必ず成功する合図ではありません。

範囲を抜けたように見えても、すぐ戻ることがあります。

また、日中に入るルールなので、終値だけのデータで検証すると、実際の順番を間違えることがあります。

今日の高値や安値を範囲作りに入れると、未来を知っていたような検証になります。

これは避ける必要があります。

## この章のまとめ

- エントリーは、取引を始める合図です。
- 売りから入るとは、下がる動きに合わせて取引を始める方法です。
- ドンチアンチャネルは、過去の高値と安値の範囲を見る考え方です。
- 今日の値段を範囲作りに入れてはいけません。
- バックテストでは、未来の情報を使わないことが大事です。
- System 1は20日ブレイクアウトを使います。
- System 1は、前回が勝ちなら次の20日合図を見送ります。
- 前回が勝ちだった場合は、55日Failsafe Breakoutを待ちます。
- 見送った合図も、仮に勝ち負けを追いかけます。
- System 2は55日ブレイクアウトをすべて取ります。
- 原典では、System 1とSystem 2の使い方に複数の形がありました。
- ブレイクアウトは、成功を保証するものではありません。
