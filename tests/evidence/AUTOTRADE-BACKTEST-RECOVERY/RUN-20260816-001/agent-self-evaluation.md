## 2. 改善優先順位

1. 運用開始前に、実機Windowsを再起動して手順書BT-MAN-17を人間操作で確認する。
2. 通常運用前に、大量履歴の読み込み上限、保持期限、バックアップ、Eドライブ障害時の復旧を設計する。
3. 再開機能を追加する場合は、途中RunのStrategyStateとチェックポイントを別設計し、安全に自動resumeできる証拠を先に作る。

## 3. 自己点検の結論
