- 承認者: ユーザー

- ユーザーの承認文: 「H3-1R改訂を承認します。v3では実M1を連続30本必須とし、不足するM30は停止してください」

## 承認した内容

1. 既存のv2 fixture/hashは、当時の承認内容を示す履歴証跡として削除・上書きしない。
2. 実行時の正本はv3 fixtureとする。
3. M30は、固定Calendarの同じsession anchorから始まる、連続した確定M1を実体として30本持つ場合だけ受理する。
4. M1が1本でも不足、重複、時刻逆行、未確定、別時間足由来、Calendar不一致、OHLCV不一致なら、SignalとTargetPositionを0件にして停止する。
5. v2のcompact入力は、歴史的に`accepted=true`を期待していた事実を保存するが、v3正本のStrategy実行入口では受理根拠にしない。

やさしい説明: 古い問題集は記録として残します。これからのプログラムは、30分足を作る材料である1分足30本を実際に確認できなければ、売買の合図を出さずに止まります。
