# P2-12-03 保護入力の権限分離の修正

初期の試行では、`root:0400` の入力を読むために、プロジェクトのデコーダを管理者権限で動かしてしまう問題が見つかった。この状態の試行は、P2-12-03の合格根拠にしない。

修正後の入力は、所有者を`root`のまま、専用グループ`autotrade-replay`だけが読める`root:autotrade-replay:0440`へ変更した。保護ディレクトリは`root:autotrade-replay:0750`であり、実行アカウント`oue`だけを専用グループへ登録した。

これにより、管理者はプロジェクトのコードを実行しない。デコーダ、品質Gate、証跡作成は通常の実行アカウントで動く。最新の正本Runは実行ID `cfab929d6d12473b9d7633691e4eeb69` である。

やさしい説明: 最初は、鍵付き箱を開けるために「何でもできる人」に翻訳機まで動かさせていました。翻訳機が書き換えられていたら危ないため、そのやり方はやめました。今は、箱を読める専用の鍵だけを普通の作業者に渡し、強い権限で翻訳機を動かさない形です。
