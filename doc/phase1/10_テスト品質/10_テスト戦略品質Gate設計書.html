テスト種別

種別対象合格条件
Unit testN、True Range、Donchian、状態遷移、ID生成、丸め。境界値、欠損値、時刻、重複を含む。
Golden testTurtle Strategy、OrderIntent、Risk入力、期待出力。固定入力で期待結果が一致し、後出し変更できない。
Integration testEvent Engine、Strategy、Risk、OMS、Adapter port。責務境界を迂回しない。
Replay test履歴イベントリプレイ、run_id、Manifest、データ版。同一Manifestで同一結果。
Reconciliation testOpen Order、Fill、Position、Account差分。不整合時に新規注文停止。
Failure injection testMarket data欠損、Broker断、Event queue停止、Secret漏洩疑い。fail-closedする。
Operational rehearsal通知、Cancel、Kill Switch、復旧、手動介入。Human Gateに必要な証跡が残る。
Secret security testSecret scan、ログマスク、Paper/Live namespace分離、HTML成果物確認。Secret実値が検出されない。マスク失敗時はCRITICAL。

観点固定入力期待出力
N / True Rangeギャップ、limit move、欠損を含むOHLC。N更新時刻、TR、欠損時fail-closed。
Donchian20/55日Entry、10/20日Exit、確定バー。Look-aheadなしのbreakout判定。
System 1勝ちブレイクフィルター直近勝ち/負けの固定系列。skipまたはentryの一貫判定。
0.5N追加0.49N、0.5N、0.51Nの価格系列。追加OrderIntent候補。

ロール損益限月切替、価格差、手数料。ロール由来PnLの分離記録。
データ異常欠損、重複、時刻逆行、異常価格。対象範囲のfail-closed。

バイアス防止

リスク禁止事項Gate
Look-ahead未確定バー、未来のロール情報、未来の勝敗結果を参照する。Replay Gateで検出。
Survivorship bias生存銘柄だけで検証する。Data Gateで対象Universe版を固定。
Data snooping検証結果を見てfixtureや期待値を変える。Golden fixture変更Human Gate。
候補別パラメータ最適化候補ごとに有利な探索範囲を後付けする。Experiment Manifest事前固定。

移行Gate

移行機械GateHuman Gate
Backtest → ShadowGolden test、Replay test、Bias Gate、コスト/ロール反映。検証結果、Unknown、対象市場の承認。
Shadow → PaperHeartbeat、リアルタイム遅延、Intent/Risk判定一致、通知。30営業日以上の観測結果とPaper設定承認。
Paper → 少額Live90日以上安定、Stop/Kill Switch/復旧リハーサル、DD15%ストレス確認。Live採用Risk値、Runbook、手動介入承認。
少額Live → 本番Live90日以上、Paper/Live差分説明、監査ログ完全性。本番移行承認、残Unknownの明示許容。

Human Gateと機械Gate

区分役割禁止事項
機械Gate再現性、一致、不整合、しきい値、停止条件を自動判定する。Unknownを自動承認しない。
Human Gate未確定事項、運用リスク、Live値、Runbook、例外許容を承認する。機械Gate失敗を根拠なしに上書きしない。

テスト証跡と再現性

証跡必須項目
Test Manifesttest_id、run_id、data_version、config_version、code_revision、engine_profile。
Input SnapshotRaw/Normalized data ref、fixture checksum、calendar、roll rule。
Output SnapshotSignalEvent、OrderIntent、RiskDecision、OrderState、Position、PnL。
Review Record承認者、指摘、採用/保留/却下、残リスク。

手動介入後再開Gate

Gate合格条件失敗時
ManualInterventionEvent Gate手動Cancel、手動ポジション調整、Broker GUI操作が監査イベントとして残っている。自動再開不可。
Reconciliation GateOpen Order、Fill、Position、AccountSnapshotがReconciliationPassedになる。新規注文停止を継続。
Warm-up GateKill Switch解除後のウォームアップ期間と最初の注文制限がHuman承認されている。Live再開不可。
