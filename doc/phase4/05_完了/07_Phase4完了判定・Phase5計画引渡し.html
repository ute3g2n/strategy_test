6.1 正常transaction sequence

  1. request boundary、型、許可scope、fingerprint、expected revisionを検査。
  2. metadata transactionを開始し、FK／unique／check／leaseを検査。
  3. domain row、transition、idempotency、auditを同一transactionへ積む。
  4. metadataをcommitし、commit receiptとrevisionを確定する。
  5. workerへreceiptを渡し、Core／file I/Oをmetadata transactionの外で実行する。
  6. marker／output hash／Evidence bundleを検証し、metadata referenceをCAS更新する。
