1. 平易なDomain概要と境界

本書は、将来の市場データを使う前に、固定local dummyだけで「費用・すべり・窓あきの仮定」「長期期間と市場数」「学習・検証・最終確認の分け方」「同じ入力なら同じ結論になる記録」を検査する設計である。実測値、Provider、契約、費用、実データを作ったり推測したりしない。

Cost／Slippage／Gapは市場別の実測パラメータではない。ASSUMPTIONとして固定し、market/logical ID、単位、適用期間、根拠種別、version/hashを持たない値は使わない。実測置換はP5-DATA-G1承認、P5-08受信Evidence、P5-09検証後に限る。

4. 型付きモジュールI/O

この表は、実装時に省略できない値と、未確定を明示するnullable値を分ける。

type Sha256 = string
type EvidenceState = "ASSUMPTION" | "MEASURED" | "UNKNOWN"
type CostPolicy = { logical_market_id:string; cost_value:number|null; slippage_value:number|null; gap_rule:string; evidence_state:EvidenceState; provenance_ref:string|null; version:string; hash:Sha256 }
type SplitPlan = { as_of_utc:string; train:[string,string]; validation:[string,string]; holdout:[string,string]; walk_forward_windows:Array<[string,string]>; hash:Sha256 }
type RunManifest = { run_id:string; scope_mode:"target_only"; target_paths:string[]; fixture_hash:Sha256|null; head_hash:Sha256|null; change_hash:Sha256|null; contract_hash:Sha256; calendar_hash:Sha256; cost_hash:Sha256; split_hash:Sha256; host_outbound_isolation:"VERIFIED"|"UNKNOWN"; usable:boolean }
function validateLocalDummy(input:RunManifest,cost:CostPolicy,split:SplitPlan):QualityDecision
モジュール入力出力副作用・冪等性
CostPolicyValidatorCostPolicy。値はnullable、根拠とhashは必須。有効な仮定又は停止コード。保存・通信なし。同一入力は同一Decision。
SplitIntegrityValidatorSplitPlan、Normalized時刻列、as-of。重複なしの区間証明又は停止コード。holdoutを変更しない。再試行は同じhashでのみ可。
ManifestValidatorRunManifestとP5-02/03参照。usable=true又はQUALITY_STOP。Evidence本文を作らない。未確認はfalse。

7. 処理順・エラー・擬似コード

この順序は、未来の情報又は未確認値が判定へ入る前に止めるためのもの。

validateLocalDummy(manifest,cost,split):
 require(manifest.scope_mode == "target_only")
 require(manifest.host_outbound_isolation == "VERIFIED")
 require_all_hashes(manifest.contract_hash,manifest.calendar_hash,manifest.cost_hash,manifest.split_hash)
 require(cost.evidence_state == "ASSUMPTION" or approved_measured_evidence(cost))
 require_non_overlapping_order(split.train,split.validation,split.holdout)
 require_holdout_never_used_before_final(split)
 require_records_at_or_before_as_of()
 return local_decision_without_market_claim()
エラー失敗/再試行停止判断
MANIFEST_HASH_MISMATCH入力を変更せず正しいhashへ戻せる時だけ再試行。Evidence、replay、P5-06/08/09/H2入力を停止。
HOLDOUT_REUSE分割を新version/hashへ作り直す。過去結果は再利用しない。収益性を含む結論を出さず停止。
HOST_ISOLATION_UNKNOWN隔離を検証してManifestを再生成するまで再試行不可。test subprocessとEvidence利用をBLOCKED。
