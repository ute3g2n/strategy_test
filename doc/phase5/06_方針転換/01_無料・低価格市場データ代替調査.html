最初に結論

「無料で、現在のP5と同じ5銘柄のCME先物を、17か月分の1分足で、再現可能に取得できる」サービスは、今回確認した範囲では見つからなかった。

無料サービスの多くは、日足、FXスポット／CFD、暗号資産、または研究用の非公式APIである。現在のP5で必要な MCL、M6A、MZC、MZS、MZW、1分足、個別限月、Calendar、Roll、Raw／Normalized／Quality／Manifest証跡を、同じ意味で満たすとは限らない。

最も現実的な低価格候補は Sierra Chart Historical Data Service である。公式説明では日足・日中足・多くの先物市場のtick履歴を提供し、Standard／Advanced packageに含まれる。公開価格はBase Standardが月26 USDである。ただし、5銘柄の実際のsymbol、2025-02-24以降の履歴、1分足、Volume／Open Interest、限月・連続系列、CSV出力を、1日分の小さな検証で確認するまでは採用しない。

完全無料を優先するなら、P5の対象を日足中心へ縮小する必要がある。 Yahoo Finance／yfinance、Nasdaq Data Link、Stooq、CME公式Settlementは日足の研究・照合候補だが、17か月の1分足からH4／H1／M30／M15を作る代替にはならない。

1. 今回の基準線と、Databentoが高く見える理由

現在のP5-08は、Databento GLBX.MDP3に対して、5つのMicro futuresを対象に、2025-02-24〜2026-08-01、主schema ohlcv-1m、日次分割、Raw DBN.zstd、SHA-256、UTC保存、Calendar／Roll／Quality／Manifest証跡を要求していた。実行RunではProviderがHTTP 402を返し、Records 0、Raw 0、Normalized 0で停止した。

画面に表示された今回の料金は、ohlcv-1m 0.78 GB × 70 USD/GB = 54.59 USD、Definition 0.09 GB = 0.16 USD、Statistics 0.09 GB = 0.09 USD、合計54.84 USDだった。Databento公式説明ではHistoricalは使用量課金で、課金サイズはスキーマや取得内容に依存する。つまり、単純に「1分足CSVを月額で買う」料金ではなく、提供される市場データの粒度と転送量に対する料金である。

比較上の注意: 月26 USDのプラットフォームや無料のAPIが安く見えても、同じものを比較しているとは限らない。日足だけ、連続銘柄だけ、スポット価格、CFDのBid価格、最大60日以内のイントラデイ、または再配布不可の研究用APIなら、現在P5の証拠要件を満たさない。

根拠: P5-08実行結果 ／ Databento usage pricing ／ Databento HTTP errors。

4. 候補別の詳しい評価

4.1 第一候補: Sierra Chart Historical Data Service

Sierra Chartの公式説明では、Historical Data Serviceは日足・日中足を提供し、多くの先物取引所と米国株についてHistorical tick-by-tick intraday dataも提供する。Historical-onlyで、リアルタイムstreamingは提供しない。Standard／Advanced packageに含まれ、Base Standard packageは26 USD/月と公開されている。Intraday dataはCSV／Text形式へexportでき、export recordはUTCで保存できる。

確認項目公式に確認できたことP5へ採用する前に実測すること
費用Base Standard 26 USD/月。Historical Data ServiceはStandard／Advancedに含まれる。税、契約期間、実際に対象市場を開くための追加費用、保存・自動取得の条件。
時間足日足、日中足、多くの先物のtick履歴。5銘柄の1分足が2025-02-24から2026-08-01まで連続して取得できるか。
Symbol公式説明はAvailable Symbolsから開く方式。MCL、M6A、MZC、MZS、MZWの実symbol、限月表記、expired contractの開き方。
Volume／Open Interest日足DataではVolume／OpenInterestの項目がある。Intraday exportにもVolumeがある。1分足のVolumeの意味、取引数、Open Interestの頻度、欠損時の扱い。
RollContinuous Futures Contractの機能はあるが、画面の連続系列をP5のvolume-front-month unadjusted ruleと同一視しない。個別限月を保存し、Rollを別計算できるか。back-adjustなしでP5 contractへ変換できるか。
ExportCSV／Textへexportでき、UTC exportが可能。固定CSV format、timezone、decimal、header、checksum、再取得差分、対象外列をmanifestへ保存できるか。

判断: 現在P5の「安くてもCME先物の意味を保ちたい」という方針には最も合う。ただし、まだ「採用済み」ではない。まずMCLとM6Aを各1営業日、次にMZC／MZS／MZWを各1営業日だけ取得して、既存Normalized schemaへ変換できることを証明する。

根拠: Historical Data Service ／ Packages and Pricing ／ Exporting and Importing Intraday Data Files ／ Edit Menu / export fields。

4.2 無料の研究ルート: Yahoo Finance／yfinance

Yahoo Financeは研究者に広く知られ、Backtraderなどの公式Data Feedにも接続される。yfinanceはOSSとしてYahooの公開APIを利用するが、Yahoo自身の公式SDKではなく、研究・教育目的で、Yahoo APIは個人利用向けと説明している。yfinanceの公式docsは利用可能なintervalを列挙し、intraday dataは直近60日を越えられないと記載する。

したがって、現在のP5の17か月1分足には明確に足りない。日足の価格推移を見るprototype、戦略の大まかな感度確認、他ソースとの日次照合には使えるが、正式なCME Micro futures Evidenceに昇格させない。

根拠: yfinance README ／ yfinance interval limits ／ Backtrader Data Feeds ／ Yahoo market coverage and delays。

4.3 Nasdaq Data Link／CHRIS、Stooq、CME公式

Nasdaq Data LinkはFree datasetとPremium datasetを分けて提供する。公式ドキュメントには、free dataは実験・探索向け、professional applicationsにはpremiumを推奨する旨と、現行ドキュメントが2026-08-31にretire予定である旨が表示される。旧QuandlのCHRIS continuous futuresは研究・OSSで広く参照されてきたが、現在のdataset availability、料金、利用権、必要なsymbolが未確認である。CHRISを「無料で今も必ず使える」とは書かない。

StooqはEODの探索・照合候補だが、現行のdownload/API key、先物symbol、履歴・利用条件が一次情報で固まっていないためUnknownにする。CME公式サイトのSettlementは、日次の公式値を照合するには最も強いが、Webの現在・前回値と過去の正式一括取得を混同しない。CMEは過去のまとまったDataをDataMine等へ分けている。

根拠: Nasdaq Data Link getting started ／ Data organization ／ CME Daily Settlements ／ CME settlement FAQ ／ CME Volume and Open Interest。

4.4 FX／CFDの無料intraday: HistData、Dukascopy、TrueFX

HistDataはFXのM1・tickを無料配布し、DukascopyはFX・Commodity・IndexのtickからmonthlyのHistorical Dataを無料でexportできる。TrueFXはFXのtop-of-book tickを無料履歴として案内する。ただし、これらはCMEの先物限月Dataではない。Bid／Ask、broker／CFD symbol、Volume、休日、Roll、契約サイズの意味が違うため、MCLやM6AなどのCME futures Evidenceへ一般化しない。

特にHistDataのFAQは、FXにVolumeがないこと、データはBidベースであること、完全性の保証がないことを説明している。これは「無料でM1がある」ことと「先物の正本として使える」ことが別である好例である。

根拠: HistData free Forex data ／ HistData FAQ ／ Dukascopy Historical Data Export ／ Dukascopy historical quotes API ／ TrueFX historical downloads ／ TrueFX terms。

4.5 一般API: Alpha Vantage／Twelve Data

Alpha Vantageは無料keyと25 requests/dayの枠を持ち、株式・FX・spot／index系CommodityのAPIを提供する。Twelve DataはBasicで8 credits/min、800 requests/dayを表示し、Commodityの広いプランは29 USD/月からと案内する。しかし、どちらも現在の5つのCME Micro futuresの個別限月1分足を、そのまま提供する根拠は確認できない。

これらは「株式・FX・一般商品を安く研究するAPI」としては有用だが、Commodity spotやindexをMCL futuresに置き換えない。使うならP5の資産種類・Data contract・要件を正式に変える。

根拠: Alpha Vantage documentation ／ Alpha Vantage premium and limits ／ Twelve Data pricing ／ Twelve Data commodities。

4.6 Cryptoへ方針転換する場合: Binance／Coinbase

Binance Public Dataは、spotとUSD-M／COIN-M futuresについて日次・月次ファイル、1分足などのklines、SHA-256 checksumを公開している。無料で再現可能なintradayの例としては非常に強い。ただし、CryptoはCME futuresと別資産であり、P5の4資産種類・Calendar・Volume・funding・continuous contract・取引時間を作り直す必要がある。Coinbaseの公開candlesは無料だが、1回300点超の要求不可や履歴不完全の可能性がある。

したがって、Cryptoを研究対象へ追加する案としては有力だが、現在のP5のDatabento代替にはならない。

根拠: Binance Public Data README ／ Binance REST API ／ Coinbase candles API。
