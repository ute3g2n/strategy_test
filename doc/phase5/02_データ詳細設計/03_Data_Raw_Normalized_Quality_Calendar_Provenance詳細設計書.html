4. 型付き入出力契約

type Sha256 = string  // lowercase hex、空値不可
type RelativeObjectPath = string // object root相対。absolute/UNC/..不可
type VersionRef = { id: string; version: string; content_hash: Sha256 }
type RawDatasetRef = { dataset_id: string; object_path: RelativeObjectPath; content_hash: Sha256;
  source_hash: Sha256; request_hash: Sha256; received_at_utc: string; source_schema_ref: VersionRef;
  catalog_ref: VersionRef; calendar_ref: VersionRef; manifest_ref: VersionRef; provenance_ref: VersionRef }
type NormalizedDatasetRef = { dataset_id: string; object_path: RelativeObjectPath; content_hash: Sha256;
  raw_content_hash: Sha256; transform_spec_ref: VersionRef; timestamp_policy_ref: VersionRef;
  timezone_policy_ref: VersionRef; unit_policy_ref: VersionRef; catalog_ref: VersionRef;
  calendar_ref: VersionRef; roll_ref: VersionRef; provenance_ref: VersionRef }
type QualityReport = { report_id: string; normalized_content_hash: Sha256; rule_set_ref: VersionRef;
  outcomes: QualityOutcome[]; usable: boolean; stop_decision?: StopDecisionRef }
type QualityOutcome = { rule_id: string; status: "PASS"|"FAIL"|"UNKNOWN"; evidence_hash: Sha256; detail_ref: string }

timestampはRFC3339 UTC instantと元timezone ID、offset、意味（event/open/close/received）を分離保持。UTC化不能、曖昧/不存在DST時刻、timezone IDまたはunit未指定は拒否する。

5. 永続化・不変性・再生成

領域正本（将来相対root）規則
Raw objectobjects/raw/{source_hash}/{content_hash}同一hashの冪等参照のみ。更新・変換混在なし。
Normalized objectobjects/normalized/{raw_hash}/{transform_hash}/{content_hash}Raw+spec一致だけ再生成。上書きなし。
Quality reportobjects/quality/{normalized_hash}/{ruleset_hash}/{report_hash}同一入力の冪等参照。PASS注入なし。
Metadata/manifestrelative path/hash/VersionRef/decision/evidence refだけ。P4 metadata DBへのRaw/Normalized本文は禁止。

再生成キー: (raw hash, transform hash, catalog hash, calendar hash, roll hash, timestamp/timezone/unit policy hash)。一つでも違えば新objectを生成し既存を再利用しない。ManifestはRaw/Normalized/Quality/Catalog/Calendar/Roll/Provenance/request/source/content hashを同時固定する。

6. 正常・失敗フロー

sequenceDiagram
  participant R as RawRetention
  participant N as Normalizer
  participant C as CalendarClassifier
  participant Q as QualityGate
  participant M as Manifest
  R->>R: validate path and hashes
  R->>N: RawDatasetRef
  N->>N: validate schema/timestamp/timezone/unit
  N->>C: NormalizedDatasetRef
  C->>Q: classification with version hashes
  Q->>Q: evaluate all rules
  alt all PASS
    Q->>M: QualityReport usable=true
  else FAIL or UNKNOWN
    Q-->>M: StopDecision; usable=false
  end

停止順序: path/hash/version不一致→即時拒否、schema/timezone/unit不明→正規化停止、Calendar/Roll不明→分類停止、Quality FAIL/UNKNOWN→manifest利用停止。停止時もhash、rule ID、reason refだけを記録し本文/Secret/実値をログへ出さない。

8. 擬似コード

function build_normalized(raw, contract, versions):
  require_relative_path(raw.object_path)
  require_hashes_match(raw, contract)
  require_all_version_hashes(raw, versions)
  require(contract.gate == "P5-DATA-G1_APPROVED")  # P5-08だけ
  records = decode_exactly(raw, raw.source_schema_ref)
  normalized = []
  for record in records:
    instant = parse_timestamp(record, contract.timestamp_policy_ref)
    require_unambiguous_timezone(instant, contract.timezone_policy_ref)
    require_declared_unit(record, contract.unit_policy_ref)
    normalized.append(transform(record, contract.transform_spec_ref))
  normalized_ref = write_new_object_only(normalized, regeneration_key(...))
  classification = classify(normalized_ref, versions.calendar, versions.roll)
  report = evaluate_all_rules(normalized_ref, classification, contract.quality_rules_ref)
  if any(report.status in ["FAIL", "UNKNOWN"]): return stop(report)
  return freeze_manifest(raw, normalized_ref, classification, report)
