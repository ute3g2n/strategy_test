1. この計画の効力

P4-H2はP5の計画入力引渡しだけを承認しており、外部Data取得、Provider、Secret、費用、外部I/Oを承認していない。P5-H1承認範囲で固定local dummyのRED→GREENと正式WSL隔離品質Gateを完了し、P5-07で旧Databentoの申請履歴を保存した。2026-08-14の方針変更により、旧Databento範囲は履歴となり、Binance Data Visionの新しいP5-DATA-G1-BINANCE-AMENDMENT-001が必要である。費用事前見積り必須ルールは廃止した。P5-08のRaw／展開CSV取得とP5-09のlocal品質Evidence生成に続き、P5-10の統合レビューを完了した。Provider条件、P5-08 host isolation、子Agent未起動、未測定execution costはOpenのままで、P5-H2候補は不成立、P5-11はP5-H2未承認でBLOCKEDである。P5-H2、追加の外部Data実行、Provider実接続、Secret、費用、Broker、Paper、Live、実資金、実Risk、Cloudは未開始のまま保持する。

現行暫定対象はBinance Spotの BTCUSDT、ETHUSDT。基底DataはSpot Kline 1m月次ZIP、保存・集計はUTC、CalendarはCRYPTO_24_7_UTCとする。API key／Secretは使用せず、Provider公開Data費用は0 USDとして扱い、内部保存・通信・実行usageは別監査する。旧初期5候補（MCL／M6A／MZC／MZS／MZW）は履歴として保持し、初期運用候補から外す。P5-08〜P5-11は、固定仮定と実測値、公開Dataのchecksum、Raw／Normalized／Quality／Cost／Gap／Holdout Evidenceを分けて扱い、利益性、Broker、Paper、Live、実資金はP5の完了判定に含めない。

2026-08-14 scope amendment: Provider変更とCrypto暫定対象の根拠は Binance Data Vision方針転換・Crypto暫定対象、決定ログに固定する。旧承認のDatabento request／RunnerをBinanceへ読み替えない。

3. 実ランタイム起動契約

直接Promptは、完全名の列挙だけで完了扱いにしない。root実行Agentが multi_agent_v1__spawn_agent で指定Orchestratorを実spawnし、CoordinatorがPrompt記載の全Agentを一体ずつspawnし、各Agent JSONの固定modelを明示して multi_agent_v1__wait_agent で完了を取得する。

起動証跡はruntime backend、dispatch mode、orchestrator_agent_id、agent_id、JSON path、model、Skills、受付／完了status、出力参照、入力・成果物・findingのpathまたは識別子、independent、review_modeを含む。管理用hash、manifest hash、stale fingerprintは追加しない。Orchestratorのagents map外でもPromptで明示されたAgentは省略しない。

P5-08〜P5-11では、固定model gpt-5.6-luna の AutoTrade_A95_ProtectedHashPolicyGuardian_v0_1 と autotrade_skill_protected_hash_policy_guard_v0_1 を各Promptへ含める。A95はData完全性・再現性identityと管理用hashの境界だけを静的判定し、hash値、Manifest、stale、fingerprint、receipt hashを計算・保存・比較・retryしない。

spawn／waitが使えない場合は RUNTIME_DISPATCH_FALLBACK_REQUIRED、LOCAL_FALLBACK_NO_SUBAGENTS、未起動Agent、理由、agent_id=N/A、independent=false、review_mode=SELF_REVIEW_FALLBACKを先に記録し、ルート責務チェックリストで継続する。起動不能は単独停止条件ではないが、未起動を独立レビュー済みと書かない。Human Gate未承認、外部I/O／Secret逸脱、UnknownのPass、Critical／High、Evidence欠落は停止する。

5. Unknownと停止

UNK-P3-01（長期Data）、UNK-P3-05（Cost／Slippage／Gap）、UNK-P3-07（Crypto Calendar適用）、UNK-P4-UI-002（font／OS baseline）、Binance利用・保持条件、P5-08 host isolation、P5-09 child dispatch、UNK-P5-BINANCE-001〜004は未解消・未承認として扱う。固定RunnerはP5-08で実行済みだが、起動不能の子Agentを独立実行・独立レビュー済みとは扱わない。UNK-P4-04D-004（host outbound isolation）はP5-06正式Evidenceで解消済みだが、外部Data実行のhost isolationへ一般化しない。

対象、期間、Spot階層、checksum、timestamp unit、通信、保存、利用条件、Calendar適用、期間分割、取得Runnerが未確定の場合、P5-DATA-G1またはP5-08を開始しない。P4固定fixtureや旧Databento／CME EvidenceからBinanceの実Data値を推定しない。Unknownを仮値でPassにしない。
