4. 発火制御図

User prompt
  |
  +-- Has explicit orchestrator, agent, skill full names?
        |
        +-- No
        |     +-- Stop for AI component tasks
        |     +-- Ask for explicit names or use approved plan
        |
        +-- Yes
              |
              +-- Is this a Phase execution plan creation task?
              |     |
              |     +-- Yes
              |          +-- Use AutoTradePhasePlanning_Orchestrator_v0_1
              |          +-- Use AutoTrade_A05_PhaseExecutionPlanner_v0_1 as primary planner
              |
              +-- Names match project generic namespace?
              |     |
              |     +-- Yes
              |          +-- Check files exist
              |          +-- Use only named components
              |
              +-- Names match phase-specific namespace?
                    |
                    +-- Is phase-specific use justified in prompt/spec?
                          |
                          +-- Yes: use only named phase-specific components
                          +-- No: stop and report misuse risk

5. 利用判断フロー

Need a component?
  |
  +-- Need to create a Phase execution plan?
  |     +-- Yes: prefer autotrade_skill_phase_execution_planning_v0_1
  |     +-- Yes: prefer AutoTrade_A05_PhaseExecutionPlanner_v0_1
  |     +-- Yes: prefer AutoTradePhasePlanning_Orchestrator_v0_1
  |
  +-- Can an existing autotrade_skill_* cover the work?
  |     +-- Yes: use existing generic skill
  |     +-- No:
  |          +-- Is the rule reusable across phases?
  |                +-- Yes: create new autotrade_skill_* with HTML spec
  |                +-- No:
  |                     +-- Is it needed only for one Phase?
  |                           +-- Yes: create autotrade_phaseX_skill_* with reason, expiry, freeze condition
  |                           +-- No: revise scope before creating
  |
  +-- Need a new Agent?
        +-- Prefer existing AutoTrade_Axx
        +-- Create new Agent only if responsibility is stable and cannot fit current 10 agents
