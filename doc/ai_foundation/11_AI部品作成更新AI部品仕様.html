1. 目的

本書は、Skill、サブエージェント、オーケストレータの作成・変更を進めるための汎用AI部品を定義する。基本フローは「既存再利用調査 → 実体作成または変更 → 対象ドキュメント更新 → レビュー → 反映」とする。

2. 構成

区分完全名責務モデル
Skillautotrade_skill_ai_component_lifecycle_v0_1再利用調査、部品作成・変更、仕様追従更新の手順を定義する。-
AgentAutoTrade_A06_AiComponentEngineer_v0_1必要最小限のSkill / Agent / Orchestrator 追加または変更を実装し、仕様更新を主担当する。gpt-5.6-luna
OrchestratorAutoTradeComponentLifecycle_Orchestrator_v0_1調査、作成・変更、文書追従、レビューを一連で統括する。gpt-5.6-terra

3. 再利用方針

観点方針
調査最初に既存の autotrade_skill_*、AutoTrade_Axx_*、既存Orchestratorを調査する。
再利用説明整理は source_reader、追跡性は traceability、HTMLは html_doc_writer、レビューは design_review を再利用する。
新設条件既存部品の組み合わせでは責務境界が曖昧になる場合だけ新設する。
変更条件既存部品を明示的に変更対象として指定された場合のみ変更する。

4. 標準フロー

1. Survey reusable components
2. Fix explicit target names and change scope
3. Create or modify skill / agent / orchestrator
4. Update foundation docs and rules
5. Review sync integrity and name control
6. Record residual risks and handoff

6. 停止条件

  • 新規作成要求なのに既存名と衝突する。
  • 変更要求なのに対象部品が存在しない。
  • 関連仕様書の追従更新を同じ変更セット内で完了できない。
  • default_orchestrator を変更しないと成立しない。
  • UnknownをPassにしないと先へ進めない。
