1. 30秒で分かる要約

2. ユーザーができること（ユースケースの全体像）

利用者は一人だけ

3. 使用イメージ（運用者が実際に行う順番）

3.1 初回準備

  1. SCREEN-01で現在状態、認証不要、禁止事項、未承認項目を確認する。
  2. SCREEN-20で提供元名、通知、自動更新を設定する。Secretの値は画面に表示しない。
  3. SCREEN-05でAsset Classと初期候補5件を選び、D1/H4/H1/M30/M15のデータ時刻と品質を確認する。
  4. SCREEN-06/07でTurtle System 1/2の版を作成し、必要な条件を入力して検証する。
  5. SCREEN-04で銘柄×時間足×ルールの運用単位を作る。Risk未入力、実シンボル未確認、重複は開始不可として表示する。

3.2 Backtest（1つの条件）

  1. SCREEN-08で「単一Run」を選び、銘柄、時間足、Strategy、期間、Risk、コスト等を入力する。設定ファイルも読み込める。
  2. 「事前検証」を押し、未入力、Manifest、データ品質、Risk未入力、未承認を確認する。不合格なら開始Buttonを押せない。
  3. 「開始」を押し、SCREEN-09でQueue、進捗、経過、残り見積を確認する。取消、停止、再実行はそれぞれ確認Dialogと操作記録を経て受け付ける。
  4. SCREEN-10/11で総損益、最大の落ち込み、取引回数、勝率、総残高、資産曲線、取引、Signalを確認する。
  5. 必要に応じて同一条件を再Runし、最新表示と内部保存を別々に確認する。

3.3 網羅検証（パラメータを振る）

  1. SCREEN-08で「網羅検証」を選び、設定ファイルまたは画面に各パラメータの下限、上限、ステップを入力する。画面の値は編集でき、設定ファイルはファイル名を確認して読み込み候補にする。
  2. VIEW-01で全組合せ数、見積時間、資源負荷、上限警告を確認し、開始確認を行う。
  3. SCREEN-09で組合せごとの進捗、成功、一部失敗、失敗、取消を確認する。
  4. SCREEN-10/12で全組合せの5指標を表で確認し、検索、絞込、並替、比較、CSV出力を行う。最良の設定をシステムが自動決定することはない。

3.4 Forward / Shadow / Paper / Live候補 / Live

  1. Backtest結果と対象単位を確認し、SCREEN-13でForwardまたはShadowを開始する。
  2. 停止する場合は停止理由を入力し、データ・注文・Positionの照合が終わるまで再開しない。
  3. SCREEN-14/18でPaper、Live候補、Liveの条件を順に確認する。未承認項目が1つでもあれば実行へ進めない。
  4. Live自動承認はHuman Gateの別モードであり、設定画面で明示的にONにしたときだけ使う。確認・取消モードと同じ確認Dialogで、ON/OFF、対象、設定版、Risk、端末、時刻を保存し、再起動後はOFFに戻す。
  5. この要件書とUIモックは実Broker・実注文へ接続しない。実運用は後続Gateと別証拠が必要である。

3.5 日常監視・異常停止・復旧

  1. SCREEN-02で全運用単位、最新データ、Heartbeat、次回判断、Signal、Position、警告を確認する。
  2. 遅延・接続断・競合・拒否をSCREEN-17で確認し、10/30/60秒の再試行後に停止する。
  3. 危険がある場合は個別停止または全体Kill Switchを二段確認で実行する。
  4. 再起動後はSCREEN-18でSnapshot、データ、注文、Positionを照合し、運用者が手動で再開する。自動再開はしない。

3.6 記録の確認・削除

  1. SCREEN-19でRun、設定版、hash、操作、承認、停止を検索する。
  2. 通常一覧から隠す操作は削除ではない。削除する場合は対象、影響、復元可否をDialogで確認し、監査ログを残す。
  3. バックアップの実保存先・実復元は後続Gateで決める。画面は未確定状態を隠さず表示する。
